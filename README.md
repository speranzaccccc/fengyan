# 私募基金净值分析工具

这是一个净值 Excel 分析工具，支持批量上传多个产品，查看单产品指标和产品对比，并导出 Excel 分析结果。

## 功能

- 一次选择多个产品净值文件。
- 按产品切换查看累计净值、区间收益、年化收益、最大回撤、波动率、夏普比率等指标。
- 自动计算近一年、近 2 年、近 3 年和成立以来指标。
- 支持多产品对比，并导出 Excel 分析结果。

## Windows EXE 云端打包

这个仓库已经配置好 GitHub Actions，可以生成 Windows 用户直接双击运行的 `基金净值分析工具.exe`。使用 exe 的电脑不需要安装 Python。

### 生成 exe

1. 打开 GitHub 仓库的 `Actions` 页面。
2. 选择 `Build Windows EXE`。
3. 点击 `Run workflow`。
4. 等待任务变成绿色对勾。
5. 在任务页面底部下载 artifact：`windows-exe-fund-analyzer`。
6. 解压后得到：

```text
基金净值分析工具.exe
使用说明.txt
```

### 使用说明

- 双击 `基金净值分析工具.exe` 即可运行。
- 支持 `.xlsx/.xlsm` 文件。
- 旧版 `.xls` 请先另存为 `.xlsx`。
- Windows 首次运行可能提示“未知发布者”，选择“更多信息”后继续运行即可。
